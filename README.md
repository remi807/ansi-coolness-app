# Ansi — Certified Cool

Eine kleine installierbare PWA: Im Browser ist Ansi der coolste Boss der Welt. In der installierten App wartet ein freundschaftlicher Plot-Twist.

## Lokal starten

```bash
npm install
npm run dev
```

## Als App installieren

- iPhone/iPad: Seite in Safari öffnen → Teilen → Zum Home-Bildschirm
- Android/Desktop: Seite in Chrome öffnen → Menü → App installieren

Die Seite wird über GitHub Pages veröffentlicht. Jeder Push auf `main` startet den Deployment-Workflow.
